# Current endpoint figures and data

This directory is the portable presentation bundle for the current
task–energy experiment. The plotted cohort is four matched seeds
`8,9,10,11`; each seed uses the same seed-specific common pretrain for the
task-only endpoint `alpha=0.0` and the selected rate-cost-weighted endpoint
`alpha=0.5`.

The filenames were retained for compatibility with the requested reference
layouts. Interpret the labels and metadata below, not the historical filename
alone.

## Literal first-stimulus comparator

The gray curve is computed separately within each seed and endpoint from the
ordinary first sequence response:

`0.5 * [align(r_A at t0, A0) + align(r_B at t0, B0)]`.

At that instant the hidden state, prior feedback state, and adaptation state
are zero. The network still follows its normal feedback-on unroll; feedback is
naturally absent because no prior prediction exists. The gray curve is not
reversal B, not a feedback-off final response, and not copied from another arm.
It is bit-identical across these endpoints because their feedforward substrate
and frozen local competition are shared.

## Provenance and interpretation

The figures and `plot_data.json` are generated by
[`tools/plot_emergent_reference_figures.py`](../../tools/plot_emergent_reference_figures.py),
which replays checkpoints and does not select a phenotype. Endpoint acceptance
is recorded separately in
[`endpoint_selection_record.json`](endpoint_selection_record.json) and detailed
in the [canonical guide](../../docs/emergent_task_energy_axis.md#dampening-calibration-and-fresh-confirmation).

Uncertainty is sample SEM across the four independent seed-level values. The
decoder holds out additive noise only; histories, orientation labels, and assay
pairs are reused. Operational continuation A and OOD reversal B should not be
generalized to all biological expected and unexpected stimuli.
